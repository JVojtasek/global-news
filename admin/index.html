Přihlášení do redakce

Tahle stránka nic neukládá na server — mluví přímo s tvým GitHubem. Bez tokenu je úplně nepoužitelná, takže nevadí, že je veřejně dostupná.

Token si vyrobíš na github.com/settings/personal-access-tokens. Vyber jen tenhle jeden repozitář a v oprávněních nastav Contents: Read and write a Actions: Read and write.

Token se uloží jen do tvého prohlížeče. Kdybys přišel o počítač, zruš ho na stejné stránce, kde jsi ho vyrobil — tím okamžitě přestane platit.
